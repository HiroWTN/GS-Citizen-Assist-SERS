# Registros dos testes com usuários

Resultados escritos na opinião média de 3 participantes

P1 - Estudante jovem - Baixa visão: opinião positiva sobre o sistema

P2 - Adulto trabalhador que atua na parte de iluminação geral - visão normal: opinião positiva mas com pontos de melhora

P3 - Adulto trabalhador que atua em outra parte - visão normal: opinião positiva geral sobre as funcionalidades do sistema
